# Laka 礼物系统配置优化：产品分析

## 结论

本 Sandbox 草稿建议采用 v0.6 方案：保留已有礼物资源库，把礼物 Tab、面板投放、角标素材、玩法配置、礼物说明 Banner 拆成独立后台能力；礼物赠送公告和 Lucky 中奖公告不建设独立全服公告后台，而是作为礼物玩法的固定事件能力维护。

这样做能降低运营重复配置，避免“展示位置、玩法、角标、公告、说明入口”互相覆盖，也让迁移、灰度、缓存和回滚有清晰边界。当前可进入 Sandbox 评审，但生产落地前必须保留并解决下方 TBD。

## Goals

- 保留已有礼物资源配置，继续由其维护名称、价格、图标、动画等基础信息。
- 拆分后台职责：Tab 管分类，面板配置管投放位置，角标配置管可复用素材，玩法配置管单一主玩法与附加条件，Banner 配置管说明内容。
- 将全服礼物公告与 Lucky 中奖公告放回礼物玩法配置，避免出现通用公告后台误覆盖关系、等级、活动等非本需求业务。
- 支持一个礼物选择多个角标，角标来源于统一素材库，不由玩法自动生成。
- 支持模板 Banner 与定制 Banner，并通过礼物玩法维护“礼物-Banner”关联。
- 覆盖迁移、灰度、缓存、回滚、埋点、异常和验收口径。

## Non-goals

- 不调整礼物价格、币种、结算、分成、礼物资源基础字段。
- 不调整 Lucky 中奖概率、奖池或返奖算法。
- 不建设通用平台公告后台，也不允许运营配置公告样式、文案、范围、跳转、队列、频控、有效期、隐私风控或兜底策略。
- 不发明 CP/Friend、Guardian、音乐优先级、Banner 素材规格、礼物详情媒体支持等生产规则。
- 不将 Sandbox 草稿视为生产 API 合同或已验证运行行为。

## Information Architecture Rationale

| 模块 | 独立原因 | 关键边界 |
| --- | --- | --- |
| 礼物资源配置 | 已有能力稳定，继续作为 gift_id、名称、价格、图标、动画源头 | 本需求只引用，不重复建设 |
| 礼物 Tab 配置 | Tab 是前端分类与区域展示结构，不应混入玩法和角标 | 修改 Tab 名称不影响 gift 绑定 |
| 礼物面板配置 | 面板只决定“哪个礼物放在哪里” | 玩法、角标、Banner 只读回显 |
| 礼物角标配置 | 素材一次上传、多礼物复用，避免逐礼物重复维护 | 不决定玩法，不自动覆盖 |
| 礼物玩法配置 | 一个礼物一个主玩法；全服与 Lucky 金额门槛属于玩法附加条件 | 不出现独立公告配置入口 |
| 礼物说明 Banner | Banner 是礼物说明入口，不是送礼触发公告 | 内容在 Banner 页维护，绑定在玩法页维护 |

## Gaps And Risks

| 风险 | 影响 | 当前处理 |
| --- | --- | --- |
| 关系类礼物失败策略未定 | CP/Friend 或 Guardian 无关系时的扣费、提示、增值结果会影响交易体验 | 保留 TBD，不写死策略 |
| 音乐礼物优先级未定 | 可能影响房间背景音乐、房主音频、静音设置和投诉风险 | 保留 TBD，仅分析字段需求 |
| Banner 文本与素材限制未定 | 会影响运营上传校验、阿语适配和客户端渲染 | 保留 TBD，不发明尺寸和字数 |
| 礼物详情媒体支持未定 | 会影响详情页信息架构、审核和加载兜底 | 保留 TBD |
| 公告服务与交易解耦要求高 | 不能因公告失败影响送礼、中奖和返奖 | SPEC 已要求失败只记日志和告警 |
| 迁移与缓存回滚复杂 | 新旧配置灰度期间可能返回不一致 | 需要新旧读取对比、异常切回旧读逻辑 |
| 多语言与 RTL 验证不足 | MENA 场景下英文/阿语公告容易截断或顺序错误 | 需补充真机或浏览器视觉验证 |

## Measurement

| 指标 | 口径 |
| --- | --- |
| 配置完整率 | 已发布且无缺失必填项的礼物玩法数 / 需要玩法配置的礼物数 |
| 公告生成率 | `gift_announcement_generated` / 达到公告门槛的成功送礼或中奖事件 |
| 公告曝光率 | 去重 `gift_announcement_impression` / `gift_announcement_generated`，按 `event_id + viewer_id` 去重 |
| 公告点击率 | `gift_announcement_click` / 去重 `gift_announcement_impression` |
| 公告丢弃率 | `gift_announcement_dropped` / `gift_announcement_generated`，按 `drop_reason` 拆分 |
| Banner 点击率 | `gift_banner_click` / Banner 曝光，按 `banner_id`、`gift_id`、`scene`、`language` 拆分 |
| 迁移一致率 | 新旧配置读取结果一致的 gift_id 数 / 灰度对比 gift_id 数 |
| 配置发布失败率 | 校验失败次数 / 发布尝试次数，按缺失字段或非法字段拆分 |
