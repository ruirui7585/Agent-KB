Rules
1. Reward Cycles (Daily / Weekly / Monthly)
This event provides Daily, Weekly, and Monthly recharge reward cycles. Each successful recharge counts simultaneously toward all applicable active cycles.
2. Currency & Independent Cycle Tracking
All cumulative recharge amounts are calculated uniformly in USD. Daily, Weekly, and Monthly maintain independent progress bars, tiers, and reward lists. Progress resets at the start of each natural cycle.
3. Tier Rewards & Claiming
Once your cumulative USD recharge reaches a tier threshold, tap Receive to claim rewards. Automatic rewards (e.g., VIP, Coins, Frames, Mounts, Titles, Medals) are credited immediately; manual rewards (e.g., Custom ID, Custom Gift, Banner Exposure) enter Pending Fulfillment — please contact Operations to arrange delivery.
4. Reward Claim Validity
Unlocked tier rewards must be claimed within the active cycle. Unclaimed rewards expire automatically once the cycle ends (exact grace/reset timezone subject to event configuration).
5. Custom ID Template Redemption Rule
A Custom ID template reward does not represent an already-assigned ID; actual Custom IDs are allocated with assistance from Operations.
If you receive multiple Custom ID template rewards from different tiers, you can redeem only one.
