# Vercel 部署快速指南

## 一、注册 Cloudinary（5分钟）

### 1. 注册账号
访问：https://cloudinary.com/
点击 "Sign up for free"

### 2. 获取密钥
注册完成后，Dashboard 会显示：
- **Cloud Name**: 例如 `dxyz123abc`
- **API Key**: 例如 `123456789012345`
- **API Secret**: 例如 `abcdefghijklmnopqrstuvwxyz`

**请保存好这三个值，稍后会用到！**

---

## 二、部署到 Vercel（10分钟）

### 方式一：GitHub 自动部署（推荐新手）

#### 1. 上传到 GitHub

```bash
cd Projects/personal/wedding-photos-vercel
git init
git add .
git commit -m "Initial commit"
```

然后在 GitHub 创建新仓库，推送代码。

#### 2. 导入到 Vercel

1. 访问：https://vercel.com/
2. 点击 "Sign Up" 用 GitHub 登录
3. 登录后点击 "Add New Project"
4. 选择你的 GitHub 仓库
5. 点击 "Import"

#### 3. 配置环境变量

在部署页面：
1. 展开 "Environment Variables"
2. 添加三个变量：

| Name | Value |
|------|-------|
| `CLOUDINARY_CLOUD_NAME` | 你的 Cloud Name |
| `CLOUDINARY_API_KEY` | 你的 API Key |
| `CLOUDINARY_API_SECRET` | 你的 API Secret |

3. 点击 "Deploy"

#### 4. 等待部署

约 1-2 分钟后部署完成，你会看到：
- **预览域名**: `https://wedding-photos-vercel-xxx.vercel.app`
- 点击 "Visit" 访问

---

### 方式二：Vercel CLI 部署（推荐开发者）

#### 1. 安装 Vercel CLI

```bash
npm install -g vercel
```

#### 2. 登录

```bash
vercel login
```

选择 GitHub 登录。

#### 3. 部署

```bash
cd Projects/personal/wedding-photos-vercel
vercel
```

按提示操作：
- Setup and deploy? **Y**
- Link to existing project? **N**
- Project name? **wedding-photos** (或自定义)
- Directory? **./**

#### 4. 设置环境变量

**方式 A：在 Vercel Dashboard 设置**

1. 访问 https://vercel.com/dashboard
2. 进入你的项目
3. Settings → Environment Variables
4. 添加三个变量（同上）

**方式 B：命令行设置**

```bash
vercel env add CLOUDINARY_CLOUD_NAME
vercel env add CLOUDINARY_API_KEY
vercel env add CLOUDINARY_API_SECRET
```

#### 5. 重新部署

```bash
vercel --prod
```

---

## 三、访问应用

部署成功后，你会获得固定域名：

- **上传页面**: `https://你的域名.vercel.app/index.html`
- **下载页面**: `https://你的域名.vercel.app/download.html`

---

## 四、自定义域名（可选）

### 1. 添加域名

在 Vercel Dashboard：
1. 进入项目 → Settings → Domains
2. 输入你的域名，例如 `wedding.example.com`
3. 点击 Add

### 2. 配置 DNS

按 Vercel 提示，在你的域名服务商添加 DNS 记录：

**方式一：A 记录（推荐）**
```
类型: A
名称: wedding
值: 76.76.21.21
```

**方式二：CNAME 记录**
```
类型: CNAME
名称: wedding
值: cname.vercel-dns.com
```

### 3. 等待生效

DNS 生效后，你可以通过自定义域名访问：
- `https://wedding.example.com/index.html`
- `https://wedding.example.com/download.html`

## 常见问题

### Q: 部署失败怎么办？

检查环境变量是否正确设置：
1. 进入 Vercel Dashboard
2. 项目 → Settings → Environment Variables
3. 确认三个变量都存在且值正确

### Q: 上传失败？

确认：
1. Cloudinary 账号正常
2. API Key 和 Secret 正确
3. 网络连接正常

### Q: 如何查看日志？

在 Vercel Dashboard：
1. 进入项目
2. Deployments → 选择部署 → Function Logs

### Q: 如何重新部署？

修改代码后：
```bash
git add .
git commit -m "Update"
git push
```

或者在本地：
```bash
vercel --prod
```
