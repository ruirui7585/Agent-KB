# 婚礼照片下载系统 - 快速使用指南

## 🚀 三种启动方式

### 方式一：局域网访问（最简单）

**适用场景**：宾客在现场，可以连接同一 WiFi

**使用步骤**：
```bash
cd Projects/personal/wedding-photos
./start-lan.sh
```

**访问地址**：`http://192.168.2.7:8080/download.html`

**优点**：
- 无需安装额外软件
- 速度快，稳定

**缺点**：
- 宾客需要连接同一 WiFi

---

### 方式二：公网访问 - Cloudflare（推荐）

**适用场景**：宾客不在现场，或无法连接同一 WiFi

**使用步骤**：
```bash
cd Projects/personal/wedding-photos
./start-public.sh
```

**访问地址**：脚本会自动生成，例如 `https://xxx.trycloudflare.com/download.html`

**优点**：
- 宾客在任何网络下都能访问
- 完全免费
- 自动安装 cloudflared

**缺点**：
- 需要安装 cloudflared（脚本会自动安装）
- 地址在重启后会变化

---

### 方式三：公网访问 - ngrok

**适用场景**：同方式二

**使用步骤**：
```bash
# 先安装 ngrok
brew install ngrok

# 启动服务器
cd Projects/personal/wedding-photos
./start-ngrok.sh
```

**访问地址**：脚本会自动生成，例如 `https://xxx.ngrok.io/download.html`

---

## 📱 使用流程

### 步骤 1：启动服务器

选择上述三种方式之一启动服务器

### 步骤 2：上传照片

1. 打开上传页面（脚本会显示地址）
2. 拖拽或点击上传照片
3. 等待上传完成

### 步骤 3：分享给宾客

**方法 A：发送链接**
- 将下载页面地址通过微信/短信发送给宾客

**方法 B：二维码**
- 宾客访问下载页面
- 页面顶部会显示二维码
- 其他宾客可以扫码访问

### 步骤 4：宾客下载

1. 宾客访问下载页面
2. 点击照片预览原图
3. 点击"下载"按钮保存照片

## 💡 常见问题

### Q: 哪种方式最适合我？

**婚礼现场使用**：
- 推荐 **方式一（局域网）**，速度最快，最稳定
- 提前在现场布置 WiFi，将密码告知宾客

**远程分享**：
- 推荐 **方式二（Cloudflare）**，免费且易用
- 宾客无需在任何特定网络下

### Q: 公网地址会变化吗？

是的，免费版公网地址会在每次重启后变化。

**解决方案**：
- 婚礼当天保持服务器运行，不要重启
- 如果必须重启，重新分享新的链接即可

### Q: 上传的照片存储在哪里？

照片存储在 `uploads/` 目录，完全在您的本地电脑上，非常安全。

### Q: 支持多少张照片？

理论上没有限制，但建议控制在 1000 张以内以保证性能。

### Q: 照片会压缩吗？

**不会**！系统支持原图上传和原图下载，完全无压缩。

### Q: 宾客需要安装什么吗？

**不需要**！宾客只需要：
- 浏览器（手机自带）
- 访问链接或扫描二维码

## ⚙️ 高级配置

### 修改端口

编辑 `server.py` 文件，修改：
```python
PORT = 8080  # 改为您想要的端口
```

### 修改上传大小限制

编辑 `server.py` 文件，修改：
```python
MAX_FILE_SIZE = 100 * 1024 * 1024  # 100MB
```

### 支持的图片格式

JPG、PNG、GIF、BMP、WebP、HEIC、HEIF
