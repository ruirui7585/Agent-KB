# Laka 竞品页面画廊（你只管上传 · 全自动切图打标）

> 定位：把 iPhone 竞品录屏与零散截图直接拖进网页，后面全部自动完成——自动去重切页面、自动拼滚动长规则、自动打好直观中文标签，铺成一屏多列的紧凑竞品页面画廊。

## 极简用法（人工只做 1 步）

1. **打开画廊**：在 Finder 双击 `start-workbench.command`（已打开 `http://localhost:3460/` 时直接使用）；
2. **直接粘贴、连续拼长图或批量拖入**：
   - **单屏截图**：飞书/系统截图完直接按 **`⌘V`**（或点右上角「粘贴截图 (⌘V)」按钮），立即上墙自动打标；
   - **多屏飞书长文档续拼**：先粘第 1 屏，点击卡片右下角 **`+续拼`**（或点开大图点右上角 **`+ 续拼下一屏`**），随后回飞书往下滚一屏截一张、切回来按一次 **`⌘V`**，自动去重吸顶栏与重叠段合成同一张高清长图；
   - **PDF / 录屏导入**：若飞书文档未禁导出，也可导出图片或 `.pdf`（或用 `Command + Shift + 5` 录屏滚一遍）直接拖入网页；
3. **自动归档查看**：
   - 系统会自动剔除手机顶部时间信号栏、自动识别页面类型并打上彩色中文标签（如 `首页推荐`、`语音房内`、`PK与榜单`、`VIP与贵族`、`后台看板` 等，宽屏 PC 后台截图会自动适配完整展示并推荐子标签如 `VIP看板`）；
   - **想改标签或新增子标签？直接鼠标点一下卡片底部的标签胶囊**，弹出菜单点一下立即秒换；点击 `+ 子标签` 可现场输入并保存自定义子标签（如 `VIP看板`、`月卡返利`）；
   - **想看大图和规则文案？点击手机缩略图**，右侧滑出高清大图、自动提取的结构亮点与一键复制文案（支持键盘 `←` `→` 快速翻页对比）。
