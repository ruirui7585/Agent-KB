# 1v1 心愿礼物后台 · 产品逻辑

> 本文档基于「心愿礼物后台可视化配置图」三页（心愿礼物面板关联配置 / 主播维度心愿数据 / 心愿礼物维度数据）反向梳理的产品逻辑，用于产品、设计、开发对齐。所有数据均为示例数据（Sample Data）。

---

## 一、功能定位与边界

1. **心愿礼物不是独立礼物资产**。后台不新建礼物，只新增一个「心愿礼物面板」用于**关联**礼物中心已有的基础礼物。礼物的名称、图标、金币价格、动画、上下架状态、结算规则一律**读取礼物中心数据**，本后台不允许重新编辑。
2. 后台由两类页面组成：
   - **配置页**：心愿礼物面板关联配置（可写，仅维护"关联关系"）。
   - **数据查询页**：主播维度心愿数据、心愿礼物维度数据（只读，仅查看，不可人工改数）。
3. 范围边界（本次不做）：特殊礼物、解锁规则、心愿价格规则、槽位/目标价值区间、主播等级权限配置、用户/主播收益人工修改、订单补录、独立礼物玩法配置、前端主播/用户页面。

---

```
首页

主播管理
礼物中心
  ├─ 礼物管理
  └─ 心愿礼物面板        ← 配置页入口
```

## 三、页面一：心愿礼物面板关联配置（配置页）

**英文副标题**：Wish Gift Panel
**页面说明**：配置哪些现有基础礼物允许主播选择为心愿礼物；该页面仅管理关联关系，不重新编辑价格、图标、动画、结算规则。

### 3.1 顶部操作（可写）
- 新增关联 / 批量启用 / 批量停用 / 导出（主按钮为 Laka 紫色）。
- 批量启用/停用作用于列表勾选行（复选框）。

### 3.2 筛选与列表字段
筛选区：礼物 ID、礼物名称、礼物中心状态（上架/下架/停用）、心愿面板状态（启用/停用）、生效状态（未生效/生效中/已失效）、更新时间、查询、重置。

列表字段（12 列）：
| 字段 | 逻辑 |
|---|---|
| 复选框 | 支持批量启用/停用/移除 |
| 礼物图标 | 读取礼物中心，只读 |
| 礼物 ID | 礼物中心唯一标识，只读 |
| 礼物名称 | 读取礼物中心，只读 |
| 当前金币价格 | **只读，例如「199 金币」**，来自礼物中心，本页不可改 |
| 礼物中心状态 | 上架/下架/停用（与心愿面板状态**分列**，互不影响） |
| 心愿面板状态 | 启用/停用（本关联关系的开关） |
| 展示排序 | 本面板内的展示顺序 |
| 生效时间 | 关联生效时间（含未来时间 = 未生效） |
| 创建人 | 操作账号 |
| 更新时间 | 最后变更时间 |
| 操作 | 编辑 / 启用 / 停用 / 移除 |

### 3.3 状态机
- **礼物中心状态**（上游决定）：上架（绿）/ 下架（红）/ 停用（红）。
- **心愿面板状态**（本页决定）：启用（绿）/ 停用（灰）。
- **生效状态**（时间决定）：未生效（未来起期，灰）/ 生效中 / 已失效（过期，红）。
- 示例需覆盖：正常启用、面板停用、礼物中心下架、尚未生效、已失效。

### 3.4 新增关联弹窗
字段：礼物 ID 搜索、礼物图标（只读）、礼物名称（只读）、当前金币价格（只读）、礼物中心状态（只读）、展示排序、生效方式（长期有效/指定时间）、开始时间、结束时间、心愿面板状态（启用/停用）。
- **校验逻辑**：若该礼物已存在于心愿礼物面板，弹窗显示错误提示「该礼物已存在于心愿礼物面板中。」并阻断关联。
- 底部：取消 / 确认关联。

## 四、页面二：主播维度心愿数据（数据查询页）

**英文副标题**：Host Wish Performance
**页面说明**：查看不同主播对心愿功能的配置、用户参与与收益表现。
**约束**：收入、付费用户、完成进度、订单数据均为只读，不可人工修改。

### 4.1 顶部汇总卡片（4 项）
- 配置心愿主播数：1,286
- 心愿付费用户数：8,420
- 心愿消费金币：3.26M 金币（**用户消费，金币，金图标**）
- 主播心愿收益钻石：3.26M 钻石（**主播收益，钻石，紫蓝图标**）

### 4.2 筛选区
日期范围（今日/昨日/最近7日/最近30日/自定义）、主播 ID、主播昵称、国家/地区、是否配置过心愿、是否产生心愿收入、心愿收益区间、查询、重置、导出。

> 注：「等级/分层」字段已移除（不再作为筛选项与列表列）。

### 4.3 列表字段（14 列）
主播头像、主播 ID、主播昵称、国家/地区、收礼资格、配置心愿天数、当前有效心愿数、心愿付费用户数、心愿完成人数、心愿消费金币、付费礼物收益钻石、主播收益钻石、心愿完成率、心愿礼物收入占比、操作。

字段口径：
- **收礼资格**：正常（绿）/ 暂停（红）。
- **付费礼物收益钻石**：仅心愿付费产生的钻石收益（示例 Layla 63.2K）。
- **主播收益钻石**：主播总钻石收益（含心愿外其他来源，示例 Layla 71.0K），与"付费礼物收益钻石"区分口径。
- **心愿礼物收入占比**：心愿收入占主播总收入比例（示例 Layla 18.5%）。
- 状态覆盖示例：正常数据 / 无心愿收入（Omar）/ 未配置心愿（Noor）/ 收礼资格暂停（Yara）。

### 4.4 查看详情抽屉（只读）
- 主播基础信息：头像、ID、昵称、国家/地区、收礼资格（**无主播等级**）。
- 统计周期数据：配置心愿天数、曝光用户数、点击用户数、付费用户数、完成人数、消费金币、主播收益钻石、付费礼物收益钻石、心愿完成率、心愿礼物收入占比。
- 当前心愿配置：主播今日配置的心愿礼物（图标/名称/目标数量/状态）。
- 配置记录：最近 5 条（日期/槽位/礼物/目标数量/生效时间）。
- **抽屉仅查看，不提供任何编辑入口。**

## 五、页面三：心愿礼物维度数据（数据查询页）

**英文副标题**：Wish Gift Performance
**页面说明**：查看不同礼物在心愿场景的配置、参与、完成、收入表现，辅助运营判断是否保留在面板。
**约束**：只读统计，不可人工改数。

### 5.1 顶部汇总卡片（4 项）
心愿面板礼物数：6｜被配置主播数：1,286｜心愿付费用户数：8,420｜心愿消费金币：3.26M 金币（金图标）。

### 5.2 筛选区
日期范围、礼物 ID、礼物名称、礼物价格区间、心愿面板状态、礼物中心状态、国家/地区、查询、重置、导出。

### 5.3 列表字段（17 列）
礼物图标、礼物 ID、礼物名称、当前金币价格、心愿面板状态、配置主播数、配置天数、礼物曝光用户数、礼物点击用户数、礼物付费用户数、礼物完成人数、赠送数量、消费金币、主播收益钻石、心愿礼物收入占比、礼物完成率、操作。

- **当前金币价格**：只读，来自礼物中心。
- **心愿面板状态**（启用绿/停用灰）与**礼物中心状态**（上架绿/下架红/停用红）分列呈现。
- **心愿礼物收入占比**：该礼物心愿收入占对应礼物总收入的占比（示例 Rose 21.3% / Golden Car 5.0%）。

### 5.4 查看趋势抽屉（只读）
- 礼物基础信息：图标、ID、名称、金币价格、礼物中心状态、心愿面板状态。
- 核心数据：配置主播数、付费用户数、完成人数、赠送数量、消费金币、主播收益钻石、心愿礼物收入占比、完成率。
- 最近 7 日趋势：轻量双折线（每日心愿消费金币=金线 / 每日心愿付费用户数=紫线），非大屏。
- 使用该礼物的主播明细 Top5：主播 ID、昵称、配置天数、心愿消费金币、心愿完成人数。
- **抽屉仅查看。**

## 六、统一指标定义与口径

| 指标 | 定义 |
|---|---|
| 心愿付费用户数 | 统计周期内，通过心愿入口成功赠送过礼物的去重用户数 |
| 心愿完成人数 | 统计周期内，至少完成过一个个人心愿目标的去重用户数 |
| 心愿消费金币 | 用户通过心愿入口成功赠送礼物消耗的金币（用户侧，金币） |
| 主播收益钻石 | 主播通过心愿订单获得的钻石收益（主播侧，钻石） |
| 心愿礼物收入占比 | 心愿收入 ÷ 主播/礼物总收入 |
| 心愿完成率 | 心愿完成人数 ÷ 心愿付费用户数 |

**币种区分原则**：用户消费用**金币**（金图标），主播收益用**钻石**（紫蓝图标），两类指标不可混用同一单位。

---

## 七、有效订单判定（数据纳入口径）

仅统计满足以下全部条件的订单：
- 通过**心愿入口**发起
- 支付成功
- 未退款、未冲正
- 非测试订单
- 非风控无效订单

同一礼物若从**普通礼物面板**赠送，不计入心愿礼物数据。

---

## 八、权限与只读约束

1. 配置页（页面一）可写范围仅限于：关联关系（新增/启用/停用/移除/排序/生效时间/面板状态）。
2. 数据查询页（页面二、三）全部为只读：不提供收入、付费用户、完成进度、订单的人工修改入口；详情/趋势抽屉均无保存/提交按钮。
3. 礼物价格、图标、动画、结算规则在任何页面均不可编辑，强制来自礼物中心。

三页面为后台导航下**独立页面**，不合并为同一页 Tab。
