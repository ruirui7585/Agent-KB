# 主播心愿数据 & 礼物心愿数据 · 字段定义

> 基于后台可视化配置图，对「主播维度心愿数据（Host Wish Performance）」与「礼物维度心愿数据（Wish Gift Performance）」的全部字段给出定义、口径、来源与只读属性。所有数据均为示例数据（Sample Data）。

---

## 通用口径（两页共用）

- **币种区分**：用户侧消耗用**金币**（金图标）；主播侧收益用**钻石**（紫蓝图标）。两类指标不可混用。
- **有效订单**：仅统计「通过心愿入口发起 + 支付成功 + 未退款 + 未冲正 + 非测试 + 非风控无效」的订单；同一礼物从普通礼物面板赠送不计入。
- **统计周期**：由页面筛选区的「日期范围」决定（今日/昨日/最近7日/最近30日/自定义）；未特别注明者均指该周期内的去重或累计值。
- **只读**：数据查询页（含抽屉）全部字段只读，不可人工修改。

---

# 一、主播维度心愿数据（Host Wish Performance）

## 1.1 顶部汇总卡片（全局聚合）

| 字段       | 英文 Key                   | 定义                     | 来源/口径      | 单位 |
| -------- | ------------------------ | ---------------------- | ---------- | -- |
| 配置心愿主播数  | host_with_wish_count     | 统计范围内，至少配置过一次心愿礼物的主播总数 | 去重主播 ID 计数 | 人  |
| 心愿付费用户数  | wish_paying_user_count   | 通过心愿入口成功赠送过礼物的去重用户总数   | 全局去重用户     | 人  |
| 心愿消费金币   | wish_consume_coin        | 用户通过心愿入口赠送礼物消耗的金币总和    | 用户侧，金币     | 金币 |
| 主播心愿收益钻石 | host_wish_income_diamond | 主播通过心愿订单获得的钻石收益总和      | 主播侧，钻石     | 钻石 |

## 1.2 筛选区字段

| 字段       | 取值 / 输入                      | 定义                   |
| -------- | ---------------------------- | -------------------- |
| 日期范围     | 今日 / 昨日 / 最近7日 / 最近30日 / 自定义 | 数据统计周期               |
| 主播 ID    | 文本                           | 主播唯一标识（如 H2001）      |
| 主播昵称     | 文本                           | 主播展示名模糊匹配            |
| 国家/地区    | 沙特 / 阿联酋 / 埃及 / …            | 主播注册或运营国家            |
| 是否配置过心愿  | 是 / 否                        | 主播是否在周期内配置过心愿        |
| 是否产生心愿收入 | 是 / 否                        | 主播是否在周期内心愿入口产生过消费/收益 |
| 心愿收益区间   | 最小~最大                        | 心愿收益钻石的数值区间过滤        |

| -------- | ------------------------ | ---------------------- | ---------------------------- | -- |

## 1.4 查看详情抽屉字段（只读）

- **主播基础信息**：主播头像、主播 ID、主播昵称、国家/地区、收礼资格（无等级字段）。
- **统计周期数据**：当前有效心愿数、心愿曝光用户数、心愿点击用户数、心愿付费用户数、心愿完成人数、心愿消费金币、付费礼物收益钻石、主播收益钻石、心愿完成率、心愿礼物收入占比。（「配置心愿天数」已移除。）
- **当前心愿配置**：主播今日配置的心愿礼物（图标 / 名称 / 目标数量 / 状态=生效中）。
- **配置记录**：最近 5 条（日期 / 槽位 / 礼物 / 目标数量 / 生效时间）。

## 2.4 查看趋势抽屉字段（只读）

- **礼物基础信息**：礼物图标、礼物 ID、礼物名称、当前金币价格、礼物中心状态、心愿面板状态。
- **核心数据**：配置主播数、心愿付费用户数、心愿完成人数、赠送数量、消费金币、主播收益钻石、心愿礼物收入占比、完成率。
- **最近 7 日趋势**：轻量双折线——每日心愿消费金币（金线）+ 每日心愿付费用户数（紫线）。
- **使用该礼物的主播明细 Top5**：主播 ID、主播昵称、配置天数、心愿消费金币、心愿完成人数。

## 三、两页字段映射对照（便于核对口径）

| 同名字段          | 主播维度口径           | 礼物维度口径           |
| ------------- | ---------------- | ---------------- |
| 心愿付费用户数       | 该主播的心愿入口去重用户     | 该礼物的心愿入口去重用户     |
| 心愿消费金币 / 消费金币 | 该主播对应心愿入口金币      | 该礼物对应心愿入口金币      |
| 主播收益钻石        | 该主播总钻石（含心愿外）     | 该礼物产生的主播钻石总和     |
| 心愿礼物收入占比      | 主播心愿收入 ÷ 主播总收入   | 礼物心愿收入 ÷ 礼物总收入   |
| 心愿完成率         | 主播完成人数 ÷ 主播付费用户数 | 礼物完成人数 ÷ 礼物付费用户数 |

> 注：page2 的「付费礼物收益钻石」为心愿付费专属；page3 无此单列，但其「主播收益钻石」同为礼物维度的主播钻石总和（含心愿来源）。两页均严格只读、均带日期筛选、均含只读详情/趋势抽屉。
