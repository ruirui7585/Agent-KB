## 8. P0 专项分析（15:24 执行）

### 8.1 SUGO：1v1 与语音房供给闭环

#### 已确认事实

- iOS 当前公开版本为 2.48.0，7 月 3 日发布；其版本说明只有性能和稳定性修复，不构成实质新功能。
- 官方资料显示 SUGO Host 可使用 Live Party、上麦、HD 语音、私密 1v1、虚拟礼物和房间管理工具。
- Host 可以独立运营或加入 Agency；Agency 承担招募、培训、排班、活动支持和绩效管理。
- 用户购买 Coins，用于礼物、Premium Interaction 和房间内身份展示；礼物形成 Host 侧价值，并经过钱包、验证和提现流程。

#### 观察与推断

- **观察**：SUGO 公开内容把公共语音房、私密 1v1 和礼物收益放在同一 Host 经营链路中。
- **推断**：其核心商业循环可能是“公共房获客与建立熟悉感 → 私密互动提升付费深度 → 礼物和身份消费 → Host/Agency 获得收益”。公开资料不足以确认每个环节的精确分成和收费。
- **对 Laka 的意义**：Laka 不应只比较前台礼物和房间玩法，还应比较 Host 招募、排班、任务、收益透明度和从房间向私聊转化的数据能力。

#### 未完成验证

- 免费消息或免费通话额度；
- 文字、图片、语音、视频各自的精确 Coin 价格；
- Host 与 Agency 分成、提现门槛和 MENA 支付方式；
- 实际房间向 1v1 的入口和转化路径。

CA-001、CA-002 更新为 `Partial`。

### 8.2 Timo 与 Timo Club：同家族双产品分化

#### 已确认事实

- 两个 Android 包均由 FAST WALL 运营，并在 2026-07-02 更新。
- Timo 强调附近的人、国家筛选、随机语音、随机视频、真人认证和 Party Room。
- Timo Club 在文字、语音和视频之外，明确增加多人视频房、休闲游戏、Tribe 社区、语音房和礼物。
- MENA 商店的开发者回复明确说明“部分高级功能需要付费”；多个地区用户评论反复提及免费消息数量有限以及后续使用 Coins。

#### 观察与推断

- **观察**：Timo 更像即时 1v1 匹配入口，Timo Club 更像“1v1＋房间＋社区＋游戏”的综合产品。
- **推断**：双包可能承担不同市场、渠道或生命周期策略，但目前没有证据证明二者共享账号、用户池、资产或后台。
- **对 Laka 的意义**：可重点研究是否需要用不同入口或轻量包区分“快速异性建联”和“房间娱乐”，但不建议仅凭商店介绍推导拆包策略。

#### 风险信号

用户评论集中反映聊天付费、余额消耗快、无法轻易转移到外部社交渠道等问题。这些只作为信任与定价风险信号，不作为确定产品规则。

CA-003 更新为 `Partial`。

### 8.3 Chamet：1v1 Host 与 Agency 管理

#### 已确认事实

- Chamet 官方覆盖 1v1、匹配、Host 列表、Party Room、直播、PK、Feed、礼物、实时翻译和地区筛选。
- 官方帮助中心说明 Host 通过虚拟礼物和请求获得收益，1v1 Host 收益按周处理，通常每周四结算。
- Agency 后台能够跟踪 1v1 时长和 Host 活跃；支持邀请 Host 和下级 Agency。
- Agency 佣金绑定 Metwallet，累计未付佣金不足 10 美元时不会打款；官方还说明上级 Agency 关系不能随意变更。

#### 观察与推断

- **观察**：Chamet 将 1v1 时长、Host 活跃、Agency 层级、培训和周结算纳入同一运营体系。
- **推断**：其 1v1 供给侧管理成熟度高于单纯依赖直播礼物的平台，核心抓手可能是“可计量通话时长＋礼物＋Agency 绩效”。精确收入公式尚未验证。
- **对 Laka 的意义**：建议检查 Laka 后台是否能统一查看女性用户的 1v1 响应、有效通话时长、收益、投诉和工会归属，而不只查看钻石总量。

CA-004 更新为 `Partial`。

### 9.1 SUGO：推荐、动态、多人互动与个人主页

![SUGO 公开 UI 截图](../assets/screenshots/sugo-ui-overview-20250703.webp)

UI 观察：

- 推荐页以人物卡片和在线状态承担陌生人发现；
- Moments 与用户发现并列，内容用于补充人物判断和互动理由；
- 多人视频和 Party 强调高视觉氛围、礼物和即时互动；
- 个人主页同时承载认证、标签、动态与进入房间的入口。

对 Laka 的启示：推荐列表和个人主页不应只展示静态资料，还需要提供“为什么现在值得互动”的在线、关系和场景信号。

### 9.2 Timo：发现、Party、私聊与真人认证

![Timo 历史 UI 截图](../assets/screenshots/timo-ui-overview-20220728.jpg)

UI 观察：

- Party Room 用麦位、礼物特效和等级身份制造热闹感；
- 即时消息页面将聊天与礼物互动放在同一关系路径；

### 9.3 Chamet：Live、1v1 Chat、Meet、Party、Moment 与 Group

![Chamet App Store 宣传截图](../assets/screenshots/chamet-chat-example-20251225.jpg)

UI 观察：

- Live 与 Party 承担娱乐和付费氛围；
- Chat 将视频互动、翻译和呼叫动作集中在一个页面；
- Meet 使用附近的人和人物卡片降低发现成本；
- Moment 提供 Host 的内容经营面；
- Group 为一次性视频互动之外提供持续关系容器。

对 Laka 的启示：1v1、语音房和持续关系不应成为彼此割裂的模块，应明确设计“发现用户 → 实时互动 → 关注/群组/私聊 → 再次召回”的跨场景路径。
