# Project Context

> 本文件用于统一 Laka 项目的基础认知，记录相对稳定的产品背景、市场定位、用户角色、核心机制、商业模式和当前阶段。
> 具体功能规则、配置参数、需求版本、数据分析和历史决策分别记录在对应文档中，不在本文件中重复维护。

## 1. 项目概述与产品定位

- **基础形态**：Laka 是一款面向海外市场（以中东为核心）的 **18+ 成年陌生人社交产品**，同时支持 iOS 和 Android，已正式上线约两年，目前处于持续运营和产品优化阶段（当前核心课题：**一对一建联体验优化**）。
- **核心模块**：推荐列表、附近的人（支持虚拟定位配置）、一对一文字聊天、随机语音匹配、一对一语音与视频、多人语音房、用户个人主页、金币与钻石虚拟资产体系。**不包含滑卡匹配模式。**
- **定位与调性**：官方定位为陌生人聊天交友产品，帮助用户在无聊、孤独或缺少陪伴时快速找到愿意回应的陌生人破冰聊天，并发展持续线上关系。部分用户带有寻找异性暧昧/调情互动的隐性预期，产品可利用异性吸引力促进互动，但**不将“聊骚”、露骨成人社交或色情内容作为官方定位**，也不以严肃婚恋或线下约会为核心，对外表达保持轻松、友好、健康和克制。

## 2. 目标市场与获客渠道

- **核心市场（中东）**：沙特阿拉伯（SA）、伊拉克（IQ）、约旦（JO）、黎巴嫩（LB）、埃及（EG）。
- **测试及扩展市场（欧洲）**：德国（DE）、法国（FR）、意大利（IT）、英国（GB）——目前视为投放测试或扩展市场，不根据单次投放认定为核心战略市场。
- **主要获客渠道**：Meta Web、Facebook iOS/Android、TikTok、Google iOS/Android、Snapchat。阶段性预算、安装数和 CPA 属于动态运营数据，不在本文件长期维护。

## 3. 核心角色与业务生态闭环

平台内涵盖 6 类基础角色：

1. **男性用户（主要金币消费端）**：发现异性用户、发起打招呼/连接、使用免费聊天卡破冰、充值并消费金币进行文字聊天/送礼/解锁一对一音视频、参与语音房互动。
2. **女性用户（主要社交供给端）**：完善个人资料、接收并回应互动、与男性用户进行文字/音视频/语音房互动，通过有效互动获得钻石，并按周在移动端发起钻石提现申请。
3. **工会长**：负责女性用户的招募、日常管理、活跃维护、互动表现跟进及提现协助，保障平台社交供给。
4. **BD**：负责拓展和维护供给侧合作关系（招募工会长、跟进供给规模与质量、协调平台与工会问题）。
5. **金币代理商**：参与男性消费侧的金币销售、充值服务与多市场渠道分发。
6. **超管**：拥有平台最高管理权限，负责平台级配置、账号与角色权限、资产与提现审核、风控治理与异常处理。

**基础业务闭环**：
```text
BD 招募并维护工会长 → 工会长招募并运营女性用户 → 女性用户提供聊天和社交互动
→ 平台通过推荐/附近的人/随机语音匹配/语音房分发用户
→ 男性用户使用免费聊天卡完成首次破冰 → 免费额度耗尽后消费金币（金币代理商提供充值渠道支持）
→ 女性用户通过互动获得钻石 → 按周在移动端发起提现申请 → 超管/运营在后台审核结算
```

## 4. 一对一建联、商业化与关系升级机制

```text
发现用户 → 产生兴趣 → 发起打招呼或连接请求 → 对方回应或接受 → 开始文字聊天
→ 使用按国家配置的免费聊天卡 → 进入金币付费聊天 → 积累亲密度 → 解锁一对一语音和视频 → 形成持续关系
```

1. **iOS 与 Android 建联差异（核心合规与统计约束）**：
   - **iOS**：受平台合规要求影响，需先发起**连接请求**，对方执行“接受”（可接受/删除/拉黑）后双方才能正式建立聊天关系。
   - **Android**：无需连接申请流程，发现感兴趣对象后可直接打招呼聊天。
   - **数据与方案要求**：由于两端建联链路不同，相关产品方案、漏斗分析和指标统计（连接申请率、聊天发起率、回复率等）**必须严格按 iOS / Android 平台拆分**，禁止混合比较。
2. **免费聊天卡与金币付费聊天**：
   - 系统按用户所属国家配置免费聊天卡数量，用于降低首次破冰门槛、建立付费前价值认知。
   - 免费聊天卡耗尽后，继续聊天消耗金币（具体每条消息金币价格、免费卡消耗单位、计费消息类型、余额不足表现等由后台配置或专项商业化需求管理）。
3. **亲密度与音视频解锁**：
   - 一对一语音和视频不是初次接触即可使用的功能，而是双方通过文字聊天积累亲密度、达到规定门槛后的**关系升级权益**，以降低陌生人直接音视频的压力与骚扰。
4. **个人主页职责**：
   - 展示头像/照片、基础信息、财富等级、魅力等级、个人标签与互动入口，用于建立用户形象、展示社交价值并促进打招呼/私聊，而非公开内容发布的社交媒体主页。

## 5. 虚拟资产与提现体系

- **双资产模型**：产品内只存在**金币（Coins）**和**钻石（Diamonds）**两种虚拟资产，产品内不建立法币账户、法币余额或法币兑换概念。
- **基础计量关系**：`1 金币 = 1 钻石`（男性用户消费 1 金币，对应女性用户基础计量获得 1 钻石；特定场景分成、奖励或冻结规则由对应需求单独说明）。
- **钻石提现规则**：女性用户每周可在移动端发起一次提现申请 → 进入运营管理后台 → 运营人员审核 → 审核结果反馈给用户（后续线下/外部结算方式由运营结算规则定义，不在产品内推断）。

## 6. 产品原则与安全治理

1. **核心产品原则**：
   - 先建立真实连接价值，再推动付费（免费聊天卡用于破冰体验）；
   - 先文字破冰，再通过亲密度升级音视频关系；
   - 平衡男性消费体验与女性供给收益激励；
   - 支持按国家差异化配置（免费卡、分发、虚拟定位、商业化参数）；
   - 严格区分 iOS 与 Android 建联路径；
   - 保持健康、克制的官方定位。
2. **安全与风控重点**：防范未成年人使用、骚扰、色情及违法内容、欺诈、虚假身份、资产作弊、恶意提现、代理商与工会作弊、隐私泄露及音视频滥用；基础治理能力涵盖举报、拉黑、删除关系、隐私控制、内容治理、账号处罚、资产与提现审核。

## 7. 核心竞品与数据分析原则

- **核心参考竞品**：**SUGO**（第一核心竞品）、**Timo**（重要参考竞品）。重点关注其用户发现、1v1 建联、免费/付费聊天、亲密度、音视频解锁、多人语音房、金币钻石体系、女用户/工会/代理商体系及合规策略。
- **数据分析必拆维度**：平台（iOS / Android）、国家、用户性别、用户发现渠道、投放渠道、新老用户、免费/付费聊天阶段、是否建立连接、是否达到亲密度门槛。
- **指标定义要求**：专项分析中须明确事件名称、触发时机、属性、用户范围、分子、分母、去重规则、时间窗口、平台/国家差异，以及与用户 ID / 会话 ID / 消息 ID / 关系 ID 的关联。口径确认前不凭单张截图下长期结论。
