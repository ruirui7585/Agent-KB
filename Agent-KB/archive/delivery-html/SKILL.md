# Delivery HTML

将 Feature Contract、本地实现、标注、决策和验证结果打包为一个可独立打开的 HTML 交付文档。

## 触发条件

- L2、L3 需求默认生成
- L1 需求若 Codex 执行包明确要求则生成，否则输出简洁完成报告
- 不得为省事跳过执行包明确要求的交付

## delivery.html 结构

```text
delivery.html
├── 需求概览（背景、目标、核心假设）
├── 用户场景与流程
├── 页面与状态矩阵（嵌入最新页面截图，非旧截图）
├── 产品规则标注（从 AnnotationSourceDocument 内联）
│   ├── 每条规则: 触发条件、判断逻辑、数据来源、权限、异常
│   └── 规则版本历史（旧版本不删除，标记 [已废弃]）
├── 权限规则
├── 边界与异常处理
├── 埋点与指标口径
├── 决策日志（编号、日期、原因、放弃方案、影响范围）
├── 验收结果（真实验证结果，非声明）
├── 旧逻辑保护清单（哪些旧逻辑未被修改）
├── 未验证项与遗留风险
└── 元信息（Feature Contract 版本、生成时间、Codex 会话 ID）
```

## 内容规则

### 规则版本追溯

每条规则显示版本链：

```
FR-012 余额不足处理
├── v1.0 (2026-08-01) 弹窗引导充值 — [已废弃]
├── v1.1 (2026-08-05) 底部 Sheet + 优惠券入口 — [当前]
│   变更原因: 弹窗关闭率高 23%，决策 D-008
```

旧版本不删除，追加新版本。

### 决策日志

```
D-008 余额不足用底部 Sheet 而非弹窗
日期: 2026-08-05
原因: 弹窗关闭率 78%，Sheet 预期提升转化
放弃方案: 页面内嵌充值（太占空间）
关联规则: FR-012
影响页面: 详情页、个人中心
```

### 嵌入资源

- 页面截图来自本次实际预览结果
- 标注数据来自最终 AnnotationSourceDocument
- 不使用旧会话截图或旧规则文本
- 不依赖外部文件或网络资源

## 生成前自检

- [ ] 文件可独立在浏览器打开
- [ ] 内容来自最终本地实现，非旧版本
- [ ] 标注与 Feature Contract 一致
- [ ] 截图是本次验证的实际页面
- [ ] 旧截图、旧规则、旧决策已移除
- [ ] 无失效绝对路径
- [ ] 未验证项已如实披露
- [ ] 验收结果真实可复现

## 禁止事项

1. 使用旧截图或旧规则文本
2. 将 Codex 推测内容标注为已确认规则
3. 隐藏未验证项或遗留风险
4. 交付文件依赖外部网络资源
5. 声称验证了未实际执行的项目
6. 使用绝对路径引用本地文件
