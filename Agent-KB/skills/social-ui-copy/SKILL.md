# Social UI Copy（原型英文文案与竞品取词规范）

## 1. 适用范围

- **适用**：移动端 App 前台英文原型（含单语英文与双语切换原型）、Feature Contract 界面文案锁定、原型英文微文案审校与修复。
- **不适用**：纯中文运营后台线框、接口字段名与代码标识。

---

## 2. 分场景取词优先级（新功能 vs 既有模块）

1. **新功能 / 新玩法 / 无现有产品对照（高频常态）**：
   `用户本轮指定 / 竞品参考图原文` ＞ `同赛道成熟头部竞品的真实英文 UI 文案` ＞ `当前项目术语表已有通用词`。
   - **禁止因现有产品没有该页面就按中文词面逐字直译**。
   - 核验竞品用词时，优先查看英文版 App 实机/商店截图（App Store / Google Play）、官方 Help Center / Zendesk 或官网英文说明，**不采信中文文章机翻的英文**。
2. **既有模块延展 / 共用主框架**：
   沿用当前项目已确认的核心导航、货币与既有页面主词（若项目索引或词表已标注“禁止继承的旧版瑕疵英文”，严禁沿用）；新增局部按钮、状态标签与弹窗文案仍优先对标成熟竞品。

---

## 3. 竞品查词与标注流程（先查后写）

1. **先查本地与参考图**：若当前项目存在专属词表（如 `ui/COPY_GLOSSARY.md`）或竞品池（如 `agents/competitor-analysis/competitor-pool.md`），先按当前需求所属模块检索对应小节（不必每次全量通读）；若用户已提供竞品截图，直接沿用图中原词，不二次回译。
2. **新词主动查成熟竞品（限时快查）**：当需求引入项目词表未覆盖的新玩法、活动、特权或状态时，Agent 须先联网检索 **1–3 个同赛道成熟竞品** 的公开英文界面、商店截图或官方帮助文档，对齐真实表达后再落图，并在画板外说明或契约中注明参考竞品。**控时上限**：单次需求联网查词最多 **1 轮并行检索（≤ 2 条搜索）**，严禁为查单词启动浏览器翻商店页；1 轮未查实则直接采用最贴近成熟竞品习惯的短表达并外标 `[文案待拍板]`。
3. **区分“通行标准”与“品牌分叉”**：
   - 成熟竞品高度通用的行业标准词（如 `Claim`、`Backpack`、`Leaderboard`、`Host`、`Agency`、`Take a Seat`、`Lock Mic`、`Contact Support`、`Help & Feedback`）可直接采用，不滥标待确认；
   - 仅当不同成熟竞品存在明显命名分叉（如 `Recharge` vs `Top Up`、`Pretty ID` vs `Unique ID`、`Vehicle` vs `Mount`）且目标产品尚未定型时，才在画板外标 `[文案待拍板：候选A/B（参考：<竞品>）]`。

---

## 4. 四条文案红线

1. **严禁中文直译**：禁止脱离社交语境的字面硬译（如把“领取奖励”译作 `Receive` 而非 `Claim`、“主播”译作 `Anchor` 而非 `Host`、“上麦/麦位”译作 `On Wheat / Wheat Position` 而非 `Take a Seat / Mic`、“经纪公会”译作 `Labor Union` 而非 `Agency`）。
2. **严禁 B 端内部词泄漏到 C 端**：除非当前页面本身面向运营、代理商或后台角色，否则 C 端前台禁止出现 `Ops`、`Fulfillment`、`Exposure`、`Backend`、`Manual` 等内部协作词，应转为成熟竞品常用的 C 端自然表达（如 `Contact Support` / `Customer Service` / `Help & Feedback`、`Processing` / `In Review`、`Featured Banner`）。
3. **移动端短表达与中英分离**：按钮、Tab、角标优先使用 1–3 词短表达；中文业务解释与术语对照统一写在画板外逻辑说明、标注或 `PRD.md`，设备画布内严禁中英混排解释。
4. **同词跨画板一致**：同一概念在同一需求的所有画板、弹窗、Toast、规则页与双语映射中必须保持唯一英文词，禁止混用同义词（如同一原型混用 `Claim`/`Receive` 或 `Mystery Man`/`Mystery Person`）。

---

## 5. 交付前自检（5 项）

1. 新功能专有名词均已对齐同赛道成熟竞品真实英文 UI（无闭门直译生造词）。
2. 未继承目标项目索引中标明“不继承”的旧版瑕疵英文。
3. C 端设备画布内无 `Ops`、`Fulfillment`、`Exposure`、`Backend`、`Manual` 等 B 端内部词泄漏，无中英混排解释。
4. 同一功能/状态在按钮、标签、Toast、规则页与跨画板间 100% 同词一致。
5. 跨竞品品牌分叉词已在画板外注明参考竞品或 `[文案待拍板]`。
