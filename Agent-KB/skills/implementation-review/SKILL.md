# Implementation Review

审查 `ui-html-build` 产出的静态产品原型。通过审查仅代表静态原型达标，不代表生产代码或接口已完成；不得因页面能打开即宣布通过，也不得因静态原型无业务点击交互而判定失败。

## 审查维度

1. **契约覆盖与静态表达**：Contract 每条规则均有静态 UI 或说明无 UI；已纳入评审范围的页面、关键状态、弹窗/Sheet/Toast 均以静态展开态完整展示，不实现未定义规则，不用文字或标注代替已确认需独立成板的 UI 分支（角色/权限/状态）。
2. **状态覆盖**：先按用户确认、Contract 与 `ui-html-build` 状态裁剪标准确定范围（低频/瞬时/被前置阻止状态可仅留文档或标注）。已选正常/禁用/成功/失败/权限受限/边界值画板完整；每个独立状态画板至少有一条位于对应 `data-state` 内的状态标注，含完整 `pageState`、`state`、`visibleWhen` 及可用/不可用操作说明。
3. **旧逻辑保护**：未废弃旧功能、旧页面导航/样式/交互及 Mock 数据未被误改或覆盖。
4. **视觉与固定画布**：风格/变量/Icon（无 Emoji/空框）一致；Marker 不遮挡关键操作；逐一用浏览器实测移动端画布 `getBoundingClientRect()` 宽高与目标设备一致（默认 `393 × 852px`），窄屏由外层滚动，画布不缩放。
5. **封面、目录、双语与后台**：
   - 封面有大/小标题及双语需求背景卡（手动编辑仅存本地草稿；未接真实 Agent 时禁用应用）；
   - 左侧固定目录直读 DOM（独立于 `annotations.json`），按“章节 → 角色·状态画板”分层，覆盖全部画板并支持原生锚点直达、整体与分组折叠及一级热区定位，关闭标注后仍可用；
   - 顶部中英文切换覆盖原型、背景卡、目录和后台，刷新记忆且无混排、不改锚点或尺寸；
   - 含后台时前后台共用唯一 `index.html`，后台目录/筛选/详情/常驻字段说明可用，建议字段明确标识，未定义权限时保持只读。
6. **技术健康**：唯一入口 `index.html`（无 `delivery.html` 或平行 HTML），可打开且非空，无控制台阻断错误、404 或失效绝对路径；`data-page-id`、画板 `id`、`data-annotation-id` 唯一且可定位，`data-contract-rule` 可追溯；不将 `file://` 误判为完整标注入口。
7. **产品标注层（`prototype-annotation`）**：
   - 单一 Runtime，`annotations.json` 为正文唯一事实源（`localStorage` 仅存显示偏好）；`pageId`、必填字段、图片附件（相对路径 + 非空 `alt`，禁 Base64/绝对路径/远程 URL）合规；
   - 右侧主面板固定最右侧（不可拖动/缩放，无页面目录或定位入口），打开不覆盖原型、隐藏释放空间且不改画板尺寸；
   - 可见目标自动显示圆形等宽 Marker（不受筛选或定位限制），点击同步展开主面板、高亮目标及右侧浮窗（不覆盖画板或主面板，外部点击关闭），详情隐藏 5 个内部字段；
   - 隐藏标注后完全消失且不改布局/目录/状态，恢复后还原状态；本地编辑复用同一表单与保存接口写回 `annotations.json`（未接 Agent 时应用禁用），公网模式隐藏所有写入/上传入口且不发写请求。

## 问题分级与自动修复规则

| 严重程度 | 判定范围 | 处理原则 |
|---|---|---|
| **阻塞** | Feature Contract 内部冲突、缺关键业务规则 | 暂停并返回 `pm-delivery-workflow` |
| **P0（必须自动修复）** | 契约偏差/伪造规则、遗漏或误合并已选角色/权限/状态画板、用标注代画板、静态表达缺失、控制台阻断错误、旧逻辑回归、重复 HTML/`delivery.html`、锚点/ID 失效重复、画布尺寸错误或缩放、封面/背景卡/双语切换/左侧目录缺失耦合、前后台拆分/缺字段说明/越权写操作、状态画板缺状态标注或属性、图片 Base64/绝对路径/外链或公网暴露上传、标注面板可拖放/含目录/遮挡画板或改变尺寸、Marker 未自动显示、联动失效、本地未写回 JSON 或与浮窗接口不同、公网暴露写入、误将 `file://` 当完整入口 | **直接局部修复**，不逐条询问用户；单问题最多修 3 轮，不重写整页、不扩大范围、不删历史文件 |
| **P1（原则上修复）** | 视觉明显偏离、标注内容不准确、图片缺 `alt`、浮窗外部点击关闭小问题 | 局部直接修复 |
| **P2（可记录不修复）** | 轻微样式差异 | 记录在发现问题清单 |

## 输出与禁止事项

```text
审查通过 / 审查通过（有 P2 备注）/ 需修复

修复清单:（已自动修复的问题）
阻塞问题:（需要返回 pm-delivery-workflow 的问题）
发现问题:（P2 记录）
未验证项:（诚实披露）
```

**禁止**：页面能打开即宣布通过；只查正常态忽略边界；只记录不修复；修复时重写整页或增写业务动态 JS 交互；因无动态交互判失败；把文字/标注当成独立画板实现；将静态原型通过表述为生产实现完成；生成重复 HTML/`delivery.html`；擅改 Contract 或虚报验证。
