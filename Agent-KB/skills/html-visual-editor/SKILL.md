# HTML Visual Editor (可视化静态编辑器 + 本地自动保存 + 自动部署 Vercel)

## 适用场景

当用户希望在浏览器中对本地静态 HTML 页面或原型进行「所见即所得」的直接修改（改文案、调样式、挪位置、换图片），且要求**所有改动自动保存写回本地 `.html` 原文件，并在更新完成后自动同步部署到 Vercel 公网（跨设备打开均为最新内容）**时使用本 Skill。

## 核心能力

1. **文字直改（0.5 秒防抖 + 失焦自动保存本地 `.html`）**：
   - 开启「页面编辑」开关后，单击页面任意文案即可直接打字修改（纯文本模式，不破坏原有标签和样式结构）。
   - 编辑期间自动拦截原有的链接跳转、按钮弹窗和表单提交。
   - 停顿 `0.5s`（500ms）或鼠标点击空白处失焦时，自动将最新 HTML 写回本地 `.html` 原文件。
2. **改完自动同步部署到 Vercel 公网（跨设备实时可见）**：
   - 每次修改自动写回本地 `.html` 后，本地服务自动进入 **6 秒静默合并倒计时**（避免连续打字频繁触发部署）；一旦停手满 6 秒无新改动，后台自动执行 `vercel deploy --prod --yes` 发布到项目的固定生产域名。
   - 若正在部署期间你又做了新修改，系统会自动排队，在当前部署完成后无缝补发一轮最新部署。
   - 面板内置 **「☁️ 自动发布: 开/关」** 开关、实时进度提示（`⏳ 停顿 6s 后自动部署...` → `🚀 正在自动部署到 Vercel 公网...` → `🌐 已同步 Vercel 公网 ✓`）、**`[打开公网 ↗]`** 链接，以及底部的 **「🚀 立即同步公网」** 一键发布按钮。
3. **尺寸缩放、样式排版与显隐微调**：
   - **8 向画布缩放**：选中组件后边框自动渲染 8 个控制点（四角与四边中点），拖拽即可实时拉大拉小；按住 `Shift` 或开启「🔒 等比」时自动按比例锁定宽高。
   - **W / H 数值与等比 Scale (%)**：支持直接输入像素 `W` / `H` 数值、一键「↺ 重置尺寸」，以及通过滑块/数值精确调整 `Scale (%)` 等比缩放并自动与拖拽位移坐标叠加保存。
   - **排版与样式微调**：内置「**B 加粗**」「左 / 居中 / 右对齐」「↕ 垂直居中」快捷按钮，以及文字颜色、背景色、字号、内边距（Padding）、外边距（Margin）、圆角（Border Radius）调节。
   - **显隐控制**：支持一键「隐藏元素」与「显示已隐藏元素并恢复」。
4. **一键复制组件、位置拖拽与同级调序**：
   - **一键复制组件**：点击「📋 复制组件」或按 `Cmd/Ctrl + D`，可在同级后方完整复制一份选中组件（自动去重并生成唯一 `id`，纯静态与 JS 渲染原型均可持久保存）。
   - **同级顺序调整**：一键将选中卡片/模块在父容器内「↑ 上移顺序」或「↓ 下移顺序」。
   - **自由拖拽挪位**：开启「拖拽移动」子模式（或按住 `Alt/Option` 拖拽）即可用鼠标自由拖动元素位置，松手即自动保存坐标；支持一键「重置位置」。
5. **图片直换（自动落盘相对路径）**：
   - 点击任意 `<img>` 或带背景图的容器，或将本地图片直接拖拽到页面图片上，即可上传替换图片。
   - 服务端自动将新图片保存至项目目录 `assets/images/` 下并使用相对路径（如 `./assets/images/ve-...png`）写回 `.html`，遵循跨设备交付规范。
6. **纯净写回与多画板/iframe 兼容 + 公网只读保护（遵循 `COMMON_UI_RULES.md` §10）**：
   - **纯静态 HTML**：写回磁盘并部署至 Vercel 的 `.html` 原文件**不残留任何编辑器工具栏、选中框、`contenteditable` 或注入脚本标签**。
   - **JS 动态渲染 / 多 `<iframe>` 画板原型**：父窗口统一挂载单个编辑面板并自动托管所有同源 `<iframe>` 画板，改动保存至项目目录 `visual-edits.json`，并自动接入极简只读补丁加载器 `.visual-editor/ve-apply.js`（仅应用已保存补丁，无任何编辑 UI 或写入能力），确保本地刷新与 Vercel 公网多端打开均展示最新修改。
   - 在非本地环境（如 `*.vercel.app` 公网域名）下自动完全禁用编辑器及所有修改能力，首次在未关联项目目录触发发布时自动执行 `vercel link --yes` 后再执行 `vercel deploy --prod --yes`。

## 快速启用方式

### 方式 1：安装配套 Chrome 本地扩展 + 启动通用后台守护服务（支持双击任意本地 `.html` 直接出现编辑入口）

1. 启动通用守护服务（支持任意本地 `file://` 与 `/__project/` 地址，端口 `4199`）：
   ```bash
   /usr/local/bin/node ~/.gemini/config/skills/html-visual-editor/scripts/universal-edit-daemon.mjs --port 4199
   ```
2. 在 Chrome 打开 `chrome://extensions/` → 打开右上角「开发者模式」→ 点「加载已解压的扩展程序」选择：
   `~/.gemini/config/skills/html-visual-editor/chrome-extension`
   → 点该扩展「详情」→ 开启 **「允许访问文件网址」**。
3. 此后从访达双击打开任意本地 `.html` 文件，页面左上角都会自动出现编辑开关（支持直接改字、调样式、挪位置、换图、自动写回原文件并发布 Vercel）。

### 方式 2：为单个项目启动本地自动保存 + Vercel 自动部署服务

```bash
/usr/local/bin/node ~/.gemini/config/skills/html-visual-editor/scripts/visual-edit-server.mjs \
  --root <html-project-dir> \
  --port 4180
```

可选参数：
- `--deploy-delay 6000`：调整停止修改后自动触发 Vercel 部署的等待毫秒数（默认 `6000`，即 6 秒）。
- `--prod-alias https://xxx.vercel.app/`：指定固定生产域名（默认自动从 `.vercel/project.json` 或目录名推断）。
- `--no-auto-deploy`：仅本地自动保存，关闭自动触发 Vercel 部署（仍可在面板手动点击「🚀 立即同步公网」）。

### 方式 3：将编辑器脚本显式注入到 HTML 文件中

```bash
/usr/local/bin/node ~/.gemini/config/skills/html-visual-editor/scripts/inject-visual-editor.mjs \
  --html <path/to/index.html>
```
